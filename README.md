**Release Notes** are a short, structured summary published alongside a software release that informs users and stakeholders about what has changed in that version.

## Typically Includes
- **New Features** – newly added functionality
- **Enhancements** – improvements to existing features
- **Bug Fixes** – issues resolved in this release
- **Known Issues** – unresolved problems users should be aware of
- **Breaking Changes** – changes that may impact existing integrations or workflows

## Purpose
Release notes help users, testers, and stakeholders quickly understand **what's new, what's fixed, and what's changed** — without having to dig through detailed technical documentation or commit history.
