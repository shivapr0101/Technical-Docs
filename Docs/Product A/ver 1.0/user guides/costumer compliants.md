 Customer Complaints – User Guide

## 1. Overview

The Customer Complaints application allows users to create, track, and manage customer complaints.

## 2. Prerequisites

Before using the application, ensure that:

- You have a valid user account.
- The Customer Complaints application is assigned to you.
- You have the required permissions.

## 3. Access the Application

1. Log in to the application.
2. Open the **Applications** menu.
3. Select **Customer Complaints**.

The Customer Complaints landing page is displayed.

## 4. Create a Complaint

To create a new complaint:

1. Open the **Customer Complaints** application.
2. Click **Create**.
3. Enter the required complaint details.
4. Select the **Complaint Type**.
5. Enter a description of the complaint.
6. Select the appropriate **Status**.
7. Click **Save**.

### Example

| Field | Value |
|---|---|
| Customer Name | John Smith |
| Complaint Type | Product Issue |
| Status | New |
| Description | Product received with damaged packaging |

> **Note:** Fields marked with an asterisk (*) are mandatory.

## 5. Search for a Complaint

1. Open the **Customer Complaints** page.
2. Enter the required search criteria.
3. Click **Search**.
4. Review the search results.

## 6. Update a Complaint

1. Search for the required complaint.
2. Select the complaint from the results.
3. Update the required information.
4. Click **Save**.

## 7. Complaint Status

A complaint can have the following statuses:

- **New** – The complaint has been created.
- **In Progress** – The complaint is being investigated.
- **Resolved** – The complaint has been resolved.
- **Closed** – The complaint has been completed.

## 8. Troubleshooting

If you cannot create or update a complaint:

1. Verify that you have the required permissions.
2. Check whether all mandatory fields are completed.
3. Refresh the application.
4. Contact your administrator if the issue persists.

## 9. Summary

You can use the Customer Complaints application to:

- Create complaints.
- Search for complaints.
- Update complaint details.
- Track complaint status.
- Manage complaints through their lifecycle.
